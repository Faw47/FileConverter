File Converter Help

Convert readable files with a preset. The app keeps conversion data on this Mac.

Convert files

  1. Drop files into the main window or choose Add Files….
  2. Select a compatible preset.
  3. Watch progress in the queue. Completed files can be revealed from the row menu.

Finder

Enable the File Converter Finder extension in System Settings → General → Login Items & Extensions. The extension reads a local, capability-filtered snapshot and sends authenticated requests to the host app.

Presets

Built-in presets can be edited and disabled. Edits are saved in the local preset document. Restore a disabled built-in preset from its editor. Custom presets can be exported before deleting.

Optional tools

FFmpeg, ImageMagick, Ghostscript, LibreOffice, and Calibre are optional. A preset is shown only when its backend is available. FFmpeg powers audio splitting and size targets; Calibre powers EPUB to PDF. Install tools separately if you need those formats.

Conflicts

With Ask, one sheet lists every existing output in the batch. Choose Replace, Keep Both, or Skip; no output is changed before the decision.
